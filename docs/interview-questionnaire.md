### 分析指引（内部）
- **重复造轮子判定**：若 Q0.1/Q0.2 多数已用网关+自动路由 → 纯路由是红海；我们的差异在「可见推荐 + 零配置入口 + 可解释」。
- **H1 验证**：Q1.1 均值若 >3.0（抗拒） → 配置接管只能做可选项（带确认/回退）；若 <2.5 → 可主推。
- **H2 验证**：Q2.4「不能」占比高 + Q2.1 高 → 非技术人群是核心楔点。
